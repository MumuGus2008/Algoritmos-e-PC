## Sobre o repositório

Repositório destinado à organização das atividades e exercícios da disciplina de Algoritmos e Pensamento Computacional.

## Organização

Os exercícios serão organizados em pastas por aula, preservando os códigos originais.

## Execução dos códigos

Para compilar arquivos em C com GCC:

```bash
gcc exercicio.c -o exercicio
./exercicio
```

Para arquivos em C++ com G++:

```bash
g++ exercicio.cpp -o exercicio
./exercicio
```

No Windows, o executável gerado pode ser executado como `exercicio.exe`.
