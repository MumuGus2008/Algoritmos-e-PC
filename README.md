## Compilação e execução

### C

```bash
gcc exercicio1.c -o exercicio1
./exercicio1
```

Se o código usar funções da biblioteca matemática, em ambientes que exigem ligação explícita:

```bash
gcc exercicio1.c -o exercicio1 -lm
```

### C++

```bash
g++ exercicio1.cpp -o exercicio1
./exercicio1
```

No Windows, execute o arquivo gerado como `exercicio1.exe`.

**Observação:** os arquivos da Aula 09 foram mantidos com a extensão `.cpp` recebida. Os exercícios que leem ou gravam arquivos de texto devem ser executados no diretório adequado. Os códigos foram organizados sem reescrever sua lógica.
